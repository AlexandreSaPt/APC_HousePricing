# APC_HousePricing

Machine Learning project on house pricing in the **Porto district (Portugal)**.
The repo holds the data-collection pipeline (scraping listings, geocoding
addresses, mapping them) and the notebooks that use the resulting data.

## Folder structure

```
APC_HousePricing/
├── data/
│   ├── porto_district_all.csv                 # raw listings (scraper output)
│   ├── porto_district_all_geocoded.csv        # listings + latitude/longitude
│   └── porto_district_all_not_found.csv       # addresses the geocoder could not resolve
├── data_scripts/
│   ├── README.md                              # installation and how to run the scripts
│   ├── idealista_scraper.py                   # 1. collect listings
│   ├── lat_long_finder.py                     # 2. geocode addresses
│   ├── plot_map.py                            # 3. plot listings on a map
│   ├── geocode_cache.json                     # geocoding cache (auto-generated)
│   └── porto_district_all_geocoded_map.html   # interactive map (generated by plot_map.py)
├── notebooks/
│   └── example.ipynb                          # example notebook
└── README.md                                  # this file
```

### What each folder is for

| Folder | Purpose |
|---|---|
| `data/` | All datasets. `porto_district_all.csv` is the raw scrape, `porto_district_all_geocoded.csv` is the version with coordinates (the one to use for modelling), and `porto_district_all_not_found.csv` lists addresses that could not be geocoded. |
| `data_scripts/` | Scripts that build the datasets, plus their cache and generated map. Installation and run instructions are in [`data_scripts/README.md`](data_scripts/README.md). |
| `notebooks/` | Jupyter notebooks for exploration and modelling. |

## Data pipeline at a glance

```
idealista_scraper.py  ->  data/porto_district_all.csv
lat_long_finder.py    ->  data/porto_district_all_geocoded.csv  (+ _not_found.csv, geocode_cache.json)
plot_map.py           ->  data_scripts/porto_district_all_geocoded_map.html
```

For setup and commands, see **[`data_scripts/README.md`](data_scripts/README.md)**.
